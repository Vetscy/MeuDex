MeuDex é um app + software open source feito por mim, caso você queira usar seu celular com multitarefas, jogar um joguinho e tal, ele será uma ótima escolha.

Ele possui suporte a teclado/mouse para jogar jogos dentro do seu celular, caso queira jogar algo divertido!

O que talvez você esteja perguntando:

P: Vai ter atualizações?
R: Sim, vai ter atualizações diárias, ou semanais, ou mensais, conforme for indo o desenvolvimento.

P: O app já está disponível para download?
R: Não, o MeuDex está em desenvolvimento. Ele está estável e bom para uso, mas precisa ser aprimorado para não utilizar muito do seu celular enquanto você joga ou esteja mexendo nas redes sociais!

P: MeuDex é um software/app que simula o Dex Samsung?
R: Exatamente, ele pode ser rodado em qualquer celular, e ele é 100% funcional. Com o tempo, você vai ver uma interface 100% complexa e funcional.

IMPORTANTE!!!

O aplicativo oficial que você precisa instalar no seu celular, esse app ele vai fazer que seu celular rode no modo desktop, tem nenhum problema, tanto que é possível usar via o celular também! Caso você seja mobilador, então você terá uma experiência de PC. Juntando o Gamehub, será uma perfeição!

A interface do aplicativo/software dentro do PC será algo que vai ser renovado, apesar disso, a interface atual e a execução dele está via .py, ou seja, ele não tem algo 100%, é uma cara muito bonita, parece mais um software aleatório.

Algo que eu irei ver em breve é o sistema de autenticação, para que o Play Guard da Playstore não seja ativado, pois ele reconhece que não tem o certificado.
